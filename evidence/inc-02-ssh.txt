ROOT CAUSE: sshd runs with StrictModes=yes. It refuses to trust an
authorized_keys file that is writable by anyone other than the owner,
because another user could append their own key and impersonate this
account. .ssh was 0777 and authorized_keys was 0666, so the key was
ignored and the only remaining method was password auth, which the
automation (BatchMode=yes) cannot use.
